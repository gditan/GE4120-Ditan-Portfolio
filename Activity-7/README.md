# Activity 7: Resume Generating
## Description
This activity was about creating a one-page professional resume using at least two Large Language Model (LLM) tools with the same prompt, then comparing their outputs to see how they differ in content, formatting, and quality.
## What Have I Learned?
* **Key concepts or skills gained:** I learned how different LLMs generate resume content and how to use AI to improve the structure, wording, and professionalism of a resume.
* **A challenge I faced and how I solved it:** I found it challenging to compare the outputs and choose the better version, so I evaluated their clarity, relevance, and formatting.
* **How I could apply or improve this in the future:** I can use AI tools to help improve my resume and other professional documents while making sure the content accurately reflects my own skills and experiences.
