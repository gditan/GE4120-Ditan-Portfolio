# Activity 6: Making a Website
## Description
This activity was about creating a one-page website for a business or personal concept by planning its layout, design, and content using website-building tools.

## What Have I Learned?
* **Key concepts or skills gained:** I learned how to design and organize a website, write effective prompts, and create a visually appealing and user-friendly layout.
* **A challenge I faced and how I solved it:** I had difficulty achieving my desired website design, so I adjusted my prompts and made changes to improve the layout.
* **How I could apply or improve this in the future:** I can use these skills to create websites for future projects, business ideas, and portfolios while improving my design and web development skills.
