# Activity 2: Personal Branding

## Description
This activity was about developing my personal brand by creating a cohesive visual identity, including a logo, tagline, color palette, typography, and resume header that reflects my personal style.
## What Have I Learned?
* **Key concepts or skills gained:** I learned how to build a consistent personal brand through visual design, typography, and color selection.
* **A challenge I faced and how I solved it:** I had difficulty choosing elements that matched my style, so I explored different combinations until I found a cohesive design.
* **How I could apply or improve this in the future:** - I can use these skills to create a more professional identity across my resume, portfolio, and other digital platforms.
