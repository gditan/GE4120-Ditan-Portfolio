# Activity 5: AI Tools Activity

## Description
This activity was about using an AI tool, creating an original prompt, improving it with the help of another AI, and comparing the results to see how prompt quality affects the generated output.

## What Have I Learned?
* **Key concepts or skills gained:** I learned how prompt engineering can improve the clarity, detail, and usefulness of AI-generated responses.
* **A challenge I faced and how I solved it:** I found it challenging to make my prompt specific enough, so I refined the instructions to get a more relevant response.
* **How I could apply or improve this in the future:** I can use prompt refinement to get better results from AI tools for schoolwork, creative projects, and other tasks.
