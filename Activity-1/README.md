# Activity 1: Presentation Design Principles
## Description
This activity was about creating a promotional poster for a coffee booth called “Free Coffee,” using visual elements, typography, and creative layout to attract attention and promote the booth.

## What Have I Learned?
* **Key concepts or skills gained:** I learned how to use typography, colors, and images effectively to create an eye-catching promotional design.
* **A challenge I faced and how I solved it:** I had difficulty arranging the elements while keeping the design balanced, so I adjusted the placement, sizes, and spacing
* **How I could apply or improve this in the future:** I can apply these design skills to future promotional materials and improve my creativity, layout, and visual communication.
