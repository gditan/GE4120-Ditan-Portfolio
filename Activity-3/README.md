# Activity 1: [Social Media Infographics & Project Documentation
]

## Description
The activity aims to develop students’ skills in information synthesis, data simplification, visual storytelling, and project documentation writing. These skills are essential for effective communication, problem-solving, and digital content creation in the modern 21st-century environment.


## What Have I Learned?
* **Key concepts or skills gained:** I learned how to simplify information, organize data, and present ideas creatively through infographics and project documentation.
* **A challenge I faced and how I solved it:** I struggled to choose which information was important, but I solved it by focusing on the key points and organizing them clearly.
* **How I could apply or improve this in the future:** - I can apply these skills to future projects by creating more informative, organized, and visually appealing outputs.
